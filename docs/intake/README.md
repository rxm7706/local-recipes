# docs/intake — the inbox

Raw imports and drops land here before triage: gist snapshots, exported chats,
pasted white papers, downloaded material. **Nothing lives here permanently** —
triage routes each item to its home: an aspiration → `docs/dreams/` (or a
companion dir of its Dream) · a how-things-work description → `docs/reference/`
· superseded/out-of-scope → `/archive/docs/` (structure-preserving) · a build
contract → never here (BMAD planning-artifacts).
