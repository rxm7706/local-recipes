sudo needs to be run in your terminal — Claude can't supply the password. Run this once in your shell:                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                    
  sudo bash -c 'printf "#!/bin/bash\n# Stub for rattler-build macOS cross-compile (hardcodes /usr/bin/codesign)\nexit 0\n" > /usr/bin/codesign && chmod +x /usr/bin/codesign'                                                                                                                                       
                                                                                                                                                                                                                                                                                                                    
  Verify it's in place:                                                                                                                                                                                                                                                                                             
  /usr/bin/codesign --version; echo "exit: $?"   # should print "exit: 0"
