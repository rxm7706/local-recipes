The Dream-to-Code factory, end to end: The Dreams (the why) → The Specs (the five-field contracts) → The Pitch (the deck family) → what's In Build, Realized, and Archived. Data regenerates from the repo (dashboard-gen).

The Dreams▸
docs/dreams/ → deck (Herald) → spec (BMAD) → build (Marshal) → realized · each Dream shows at its FURTHEST stage — ▤ deck · § spec · ⚙ project · n/n live build carry its full chain
The Specs▸
_bmad-output/projects/*/planning-artifacts/specs/ — every BMAD-Method Spec: five-field contract + companions, derived from its append-only memlog. Legacy docs/specs/ is excluded.
Story Specs (Row 7)▸
per-story coverage — done stories vs. tracked flat spec files (spec-[0-9]*.md). Gap = shipped stories without durable per-story intent/acceptance-criteria docs.
Sync & Health▸
the standing detectors — each guards one contract and runs in ~1s. Red is not failure, it is the loop working: reconcile via the SYNC-RUNBOOK, then re-stamp the baseline. A detector that cannot run here reports unknown rather than claiming green.
Campaigns▸
program-scale efforts across the BMAD projects — each campaign is a roster of parallel chains/lines with live per-row state. Completed campaigns collapse and keep their durable record; the active campaign leads.
Fleet▸
Dream → Code, per project — every stage of the chain, its furthest reach, when it last moved, and the shipped version. Dots left→right: Dream · Deck · Spec · Rsch · Brief · PRD · Arch · Epics · Code; hover a dot for its date, click a row for the full ledger.
These are chain stages, not Dream states — a different axis from The Guild below, which counts Dreams per state. backfilled = the chain was retro-fitted after the fact (mandated for anything that shipped before the model existed) — true history, not an error. overtaken = the Spec still carries open questions while its PRD and architecture already exist.
The Pitch▸
presentations/<slug>/ — the deck family. Dots = the 6-artifact standard: prototype · exec summary · infographic trio · marp sources · standalone · pptx pair. Cards link to the repo.
The Guild▸
Every station, everything it owns — the accountability view the owner: through-line exists for. All eight Smiths render, including empty ones, so a thin station is visible rather than absent. Click a row for its Dreams.
Counts are Dream states, not chain stages — this is a different axis from Fleet above, which tracks the 9-stage Dream→Code chain per project. A Dream sits in exactly one state; practice is outside the lifecycle (tended, never finished).
