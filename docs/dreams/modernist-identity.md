# Modernist identity — the family reads as one system

## The Dream

Everything pyforge presents — decks, dashboards, docs, wordmarks, exports —
speaks **one visual language**: the Modernist system. Flat, architectural,
Archivo throughout; light `#f3f2f2`, ink `#201e1d`, one red accent
`#ec3013`/`#c22a10`; visible grid, 2px rules, zero corner radius, flush-left
labels, black-and-white photography. Put any two artifacts side by side and
they are unmistakably siblings.

## What is real (the core)

- The **Modernist design system** project in Claude Design (`fbc1d6c8-…`):
  tokenized stylesheet, component pages, templates, thumbnail — **bound to all
  seven family decks** (genesis + six persona chapters; `agentic-sdlc` remains
  the grandfathered Space-Grotesk origin).
- The family grammar codified in `presentation-deck.md` (design defaults,
  per-deck font-link gotcha) and proven across ~100 slides.
- The **Wordmark** and banner assets (agentic-sdlc Design project).

## The frontier

- **Design tokens round-trip**: the pipeline found in the Sentinel project —
  `tokens.json` (+ light/figma/pptx variants), `figma-variables-to-tokens`,
  `tokens-to-potx` / `potx-to-tokens`, `merge-tokens` — wire it so Modernist
  tokens drive Figma, **editable PPTX templates** ([[deckcraft]]), and the deck
  engine from one source.
- Extend the language to the **program console** (`docs/dashboard/`) and doc
  surfaces so telemetry looks like the decks.
- A Modernist wordmark/identity kit for the pyforge distributions themselves.

- **2026-07-23** — Dream retro-seeded; token-pipeline assets discovered in the
