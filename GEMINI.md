# Gemini & Antigravity Operational Manual — read AGENTS.md

This repository is **Dream-first, spec-driven, and framework-neutral**. Read **`AGENTS.md`** at the repository root for full conventions.

---

## 1. Core Operational Principles (ALWAYS ENFORCED)

1. **Think Before Coding**: State assumptions explicitly; present interpretations for ambiguous prompts rather than guessing silently.
2. **Simplicity First**: Minimum surgical code that solves the problem. Nothing speculative.
3. **Surgical Changes**: Touch only what the task requires; match existing repo style and docstring formatting.
4. **Goal-Driven Local Verification**: Transform tasks into verifiable goals; loop until 100% verified locally. Never use remote CI on GitHub Actions as a debugging plane.
5. **Dream to Code, Always**: Every effort enters through BMAD: a **Dream seed** in `docs/dreams/<slug>.md` first, then `bmad-spec` derives the Spec, then a numbered Story in `epics.md`, then code. Gap-closure and fixes are not exempt.

## 2. Auto-Memory Engine Integration

At session boot and before planning or implementing features:
- **Inspect Repository Memory Index:** Read `.claude/memory/MEMORY.md` to load accumulated post-mortems, user rulings, and failure-mode traps.
- **Key Auto-Memory Traps to Avoid:**
  - `feedback_replicate_every_triggered_ci_lane_locally.md`: Run every triggered CI lane locally before opening/updating a PR.
  - `feedback_write_baseline_after_git_add.md`: Stage new/modified files (`git add`) BEFORE running `--write-baseline`.
  - `feedback_parallel_agent_pr_needs_the_whole_chain.md`: PRs require the entire chain (Dream append, CAPs, Story, story spec, ledger row).
  - `feedback_coverage_gates_ci_needs_per_station_env.md`: Always evaluate coverage floors per station package.
  - `feedback_no_courtesy_comments.md`: No AI attribution lines (`Co-Authored-By`, "Generated by AI") in commits.

## 3. Mandatory Pre-PR Verification Protocol (100% LOCAL PASS REQUIRED)

Before creating or pushing any PR touching non-recipe paths (`src/`, `docs/`, `_bmad-output/`, `pixi.toml`):

1. **Station Test Suite Verification:**
   `pixi run -e pyforge-<station> pyforge-<station>-test`
2. **Detector & Merge Gate Audit:**
   `pixi run -e pyforge-guild pr-preflight`
3. **Doctor & Dream Hygiene Audit:**
   `pixi run --frozen -e pyforge-doctor pyforge-doctor-test` (ensure new dreams are registered in `docs/dreams/README.md`)
4. **Coverage Gates Audit:**
   `pixi run -e pyforge-steward python scripts/coverage_gates_ci.py --suites unit`
5. **Multi-Spec Surface Baseline Audit:**
   Check drift with `pixi run -e pyforge-guild python -m pyforge.doctor.sources spec-surface` and re-stamp scoped baselines (`--write-baseline --spec <project>/<spec>`) for **all** touched spec surfaces after `git add`.
6. **PR Mechanics & Labeling:**
   - Any change outside `recipes/` -> add `maintenance` label: `gh pr edit <n> --repo rxm7706/local-recipes --add-label maintenance`.
   - `pixi.toml` changed -> export `environment.yaml`: `pixi project export conda-environment -e build > environment.yaml` and run `pixi run -e pyforge-guild pyforge-station-tests`.
   - Merge with `--merge`, never squash: `gh pr merge <n> --merge`.

## 4. Tier Model Rules

| Tier | Location | Purpose | Git Status |
| :--- | :--- | :--- | :--- |
| **0 — Dream** | `docs/dreams/*.md` | Raw human aspiration / starting point | Tracked, permanent |
| **1 — Legacy Spec** | `docs/specs/*.md` | Former intake specs (superseded by Tier 2) | Tracked, phasing out |
| **2 — Spec & Planning (BMAD)** | `_bmad-output/projects/<slug>/planning-artifacts/` | Active `bmad-spec` output, PRD, architecture, epics | Tracked, permanent |
| **3 — Execution Output** | `_bmad-output/projects/<slug>/implementation-artifacts/` | Story scratch files, sprint YAMLs | **Gitignored / local-only** |

*Rule:* Active specs live in Tier 2. Never hand-author new specs in `docs/specs/` and never track files in Tier-3 `implementation-artifacts/`.
