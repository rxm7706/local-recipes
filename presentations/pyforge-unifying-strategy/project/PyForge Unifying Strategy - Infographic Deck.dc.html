06

One chrome — django-pyforge · CAP-1

App switcher

Entries derive from each portal's registration seam — never a path list. The seam carries owner, backup, work_class, promotion date; the Guildhall refuses to tile 01/02 work.

Base layout + theme

OIDC-aware pyforge/base.html, Modernist theme, WhiteNoise assets, zero external CDNs. Portals extend it and inherit switcher + auth context.

Proof, not promise

Identical chrome, zero duplicated files — a test fails if a portal ships its own copy. A portal that owns chrome has violated the contract.

Reusable-app convention: distribution django-<station> · module django_<station>_<app> · label <station>_<app> — and a model never moves between apps.

Every station has a service face · CAP-4

The wire rules — era discipline
Accept 2025-03-26 → 2026-07-28 — the fleet is split; pinning either end alone rejects real traffic.
Echo the client's revision — a client aborts on an unknown one even when it is newer.
Never branch on a client's name. Only the declared revision decides.
Disconnect survival — outcome, not extension
start/get over a durable store — SEP-2663's own lifecycle; adopting Tasks later is a wire-layer swap.
The handle is a capability — opaque, high-entropy, TTL'd.
Never: progress notifications, sticky sessions, stream replay. Keep-alives well under 30 s.
Success: an agent completes a multi-minute operation across a simulated ingress disconnect — and retrieves the result from a different replica.

14

Revocable, delivered, flippable · CAP-12 + CAP-13

Identity

Authorization derives from IdP roles. Revoke at the IdP — access is gone on the next request. Nothing cached, nothing to chase.

Secrets

Pod specs carry references only. In-estate vaulting is go-sops + age; HashiCorp Vault stays a profile adapter outside the image.

Flags

OpenFeature flagd FILE resolver — in-process, full targeting engine, zero egress. One change flips Django, service and CLI with no redeploy.

6
conda-forge builds were the committed price — 4 OpenFeature feedstocks (absent from anaconda.org entirely) + a cachebox 5.x build + liquibase 5.0.4+ with the PostgreSQL JDBC driver vendored. The air-gap gate is a gate, not a warning.
