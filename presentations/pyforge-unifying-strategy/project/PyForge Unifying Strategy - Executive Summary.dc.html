Eight stations. One foundry. One estate.

PyForge's eight capability stations each shipped as an excellent CLI — and stopped there. Foundry Platform (src/platform/) mounts them under one interface, one OIDC session, one command grammar, one event backbone and one query plane, on a modular monolith carrying exactly PostgreSQL + Redis + Kubernetes. The governance mandate rides with it: schema change auditable by database privilege, identity revocable at the IdP, failure contained by tested invariants.
