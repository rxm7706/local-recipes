The honest finding · verified 2026-07-25

The flagship command does not exist

# the intake toolchain spec's flagship lock task
pdm export --format pylock --override-platform=linux --override-platform=macos …
# `pdm export` has no such flag. Platform targeting lives on `pdm lock --platform`.
…and the format does not promise it either

PEP 751 does not guarantee multi-platform lockfiles. It uses environment markers — intent, not a cross-compilation guarantee.

AD-2 · one lock, derived exports

Exactly one Workspace Lock is authoritative. Every derived artifact is generated from one pinned commit SHA and drift-checked against it.

AD-3 · proven, never inferred

For every platform × every deployable Environment, a gate materializes it from the lock. Coverage is reported per platform, never as one boolean.

AD-17: every plane and cross-cutting concern resolves to exactly one accountable station of the PyForge Guild. A capability with no station — or one claimed by two — is a defect at the same severity.

The intake spec's five agent roles (Architect · Developer · DevOps · Security · Compliance) map onto the eight Smiths. Three stations stayed unmapped — Herald, Doctor, Scribe: communication, diagnostics, memory. The spec covered doing, not observing, explaining or remembering.

CAP-6 · the evidence chain

Compliance is a build artifact

SBOM
AD-11 · from the artifact, not the lock

Generated inside the built artifact with populated dependency edges. A flat inventory answers "do we ship X?" but never "what reaches X?" — and exploitability analysis needs the second. CycloneDX 1.7 is ECMA-424: the version is pinned, never implicit.

Provenance
AD-12 · SLSA L1 floor, L2 goal

Provenance was entirely absent from the intake set — the SBOM said what was in an artifact, nothing said how it came to be. An unattested artifact does not deploy to any Stage whose promotion policy requires approval.

The gate
AD-6 · Warden, by integration

PyForge Warden already ships a strict superset — so Unity consumes it as a CLI in its own lean Environment. Never a library import, never CI-only. The exit code derives from the report file.
