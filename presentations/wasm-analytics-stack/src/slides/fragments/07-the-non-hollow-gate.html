CAP-4 · FR-12 · FR-13

The gate must be able to fail

The isolation claim is mechanically verified, not asserted — and the proof that the verification is real is that it can be made to break on purpose.

AD-4 · the meta-test, from version one

The gate runs the compiled component under a Wasmtime host granted only its WIT-declared capabilities and fails on any host interaction beyond them.

Then it proves itself: widen the declared capability surface without a matching WIT change and the gate must fail. A gate that always passes is not a gate.

# static import scan over source + resolved closure

Direct or transitive. It fails the build, not a later runtime error — because violating it means shipping a component that either will not build under componentize-py or depends on the unmaintained wheel project this project refuses to rely on.
