The problem

Autonomous coding fails two ways: unattended agents ship plausible-but-wrong code, or humans review everything and the speed evaporates. Marshal's answer is structural: deterministic orchestration, spec gates before merge, scope checks on frozen surfaces, and independent verification — gates are never weakened to raise the autonomy share.

Escalation & the ledger

When it blocks

The loop defers with a ledger entry (deferred-work.md) or escalates to a named human — never a silent skip, never a quiet workaround.

What it writes

Run journals with weighted token spend, ATTENTION files at gates, labeled merge commits — the line is auditable end-to-end.

The creed
Run the line. Hold the gates. Ship validated code.
Speed from structure, trust from gates. The loop does the driving; humans decide exactly where deciding matters.
