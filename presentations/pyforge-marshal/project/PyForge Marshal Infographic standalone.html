The problem

Autonomous coding fails two ways: unattended agents ship plausible-but-wrong code, or humans review everything and the speed evaporates. Marshal's answer is structural: deterministic orchestration, spec gates before merge, scope checks on frozen surfaces, and independent verification — gates are never weakened to raise the autonomy share.

06

Three ways work flows through Marshal

Flow A · one attended story

The judgment-heavy path. A human drives with bmad-dev-auto or approves each spec at the gate; the harness still owns verify + scope-check. Best for scaffolds, design-heavy work, parity checks, publishes.

marshal preflight → bmad-loop run --story 2.1 (per-story gate)
Flow B · an epic, loop-gated

The workhorse that shipped Atlas and Warden. Approve once per story-spec or per epic; the loop dev→review→verify→merges the batch; deferrals land in the ledger, escalations pause.

marshal init <slug> → bmad-loop run --epic 3
Flow C · the unattended fleet

Eight concurrent loop homes on one machine, gate_mode none — the AI review pass still standing, every escalation still pausing, story specs promoted before teardown. Wake to merged code and a paper trail.

marshal homes → 8× bmad-loop run (fleet, overnight)

The contract behind the commands

785 fast tests + 8 slow real-git tests. Every finding a coded MRS-* envelope — agents always receive parseable output. Frozen exit-code domain {0,1,2,3,4,130}. Exactly one harness seam (FR-52), enforced by an import-linter contract that fails the build on any other reference. Teardown interrogates git before touching anything: uncommitted or unmerged work refuses without an explicit --force. Idempotent re-runs converge. Wrap, never absorb — the engine stays upstream, the fork stays a bounded swap.

The execution doctrine · ratified 2026-07-31

Skills are the unit of execution · the harness is the unit of governance · station verdicts stay independent. The thing that governs the agent is deliberately not a skill — and Marshal sequences on verdicts it never authors: gating reads each station's durable verdict artifact, pinned to the revision it judged. Marshal never runs the judge.

13

Escalation & the ledger

When it blocks

The loop defers with a ledger entry (deferred-work.md) or escalates to a named human — never a silent skip, never a quiet workaround. An escalation pauses the run; it never resolves itself.

What it writes

Run journals with weighted token spend, ATTENTION files at gates, labeled merge commits, promoted story specs that survive teardown — the line is auditable end-to-end.

What each leader gets

Solo developer

A second shift. The loop ships the mechanical bulk overnight inside gates you set; your attention goes only where judgment matters. 128 stories of proof, on one machine.

Team lead

A review floor that never sleeps and never rubber-stamps: the independent multi-lens pass is standing at every autonomy level, and scope-checks make “what changed” a machine question.

Engineering manager

A board that cannot lie: sprint feeds regenerated from ledgers, ten detectors patrolling the artifacts, per-story token spend journaled, deferrals durable instead of vanishing.

CTO / executive

Autonomy with an audit trail: every merge behind a green verify, every escalation a recorded human decision, cost ceilings structural, and the whole line local-first — no hosted control plane.

15

At enterprise scale — air-gapped, portable, policy-driven

Three policy layers, pure

Marshal defaults → project policy → invocation flags; last wins, per-key provenance, no fourth layer. Site-wide enterprise config is materialized at install time into the defaults layer — composition stays pure at runtime.

Internal tooling mounts, never forks

Internal MCP servers (Jira, Confluence, knowledge bases) enter through the policy-declared tool surface, rendered per loop home; proprietary agent CLIs enter as declarative adapter profiles. No factory fork required.

Local-first, offline by default

No hosted control plane, no telemetry, no account. Network use is never silent; journals and gate records are self-owned — vendor retention windows and transcript formats cannot orphan the audit trail.
