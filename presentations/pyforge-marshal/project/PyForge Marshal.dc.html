Mindset 01

Anti-vibe pragmatism

What Marshal rejects

"Good intentions." "Close enough." Prompt-and-pray output whose architectural choices are buried in the code. Vibe coding at any scale.

What Marshal enforces

Strict structural inputs only. A sub-agent that deviates from the system specification is flagged instantly and forced into a corrective iteration — until the code matches the contract.

Responsibilities

The factory loop

01 · Spec marshalling

Ingest the Spec — the Dream solidified — and shard it into targeted, isolated instruction blocks per sub-agent.

02 · Agent mobilization

Spawn and monitor tactical sub-agents per role — tests, logic, documentation — each on its own tight context.

03 · Defect containment

Intercept errors, compile stdout/stderr from failed runs, and pipe them back as explicit instructions for automated self-healing.

# initialize a blueprint from a specification
marshal init --spec ./docs/system_spec.md
# spin the factory, assign sub-agents, iterate
marshal factory spin --pipeline standard
# evaluate against tests; self-heal on failure
marshal gate evaluate --suite unit-tests
# pass pristine artifacts to the crew
marshal deploy --output ./build-artifacts
