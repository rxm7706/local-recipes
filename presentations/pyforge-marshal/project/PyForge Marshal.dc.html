Why a factory

Autonomy fails two ways

Unattended

Agents ship plausible-but-wrong code — confident, fast, subtly broken. The cost surfaces weeks later, in production.

Over-supervised

Humans review everything and the speed you bought evaporates into meetings. The agent becomes an expensive autocomplete.

Marshal’s answer is structural: spec gates before merge · scope checks on frozen surfaces · independent verification — and gates are never weakened to raise the autonomy share. Proof: 128 stories shipped, 0 frozen-surface violations reaching a merge.

Mindset 01

Anti-vibe pragmatism

What Marshal rejects

"Good intentions." "Close enough." Prompt-and-pray output whose architectural choices are buried in the code. Vibe coding at any scale.

What Marshal enforces

Strict structural inputs only. A sub-agent that deviates from the system specification is flagged instantly and forced into a corrective iteration — until the code matches the contract.

Judgment-heavy work driven interactively; the harness still owns verify + scope-check. Scaffolds, design, publishes.

The marshal CLI is real

init · homes · preflight

Provision an isolated loop home (worktree + branch + Tier-3 backlink) — prove N homes isolated, and name every blocking finding before minute 0.

config · teardown · --version

Layered policy with per-key provenance, rendered to the engine. Teardown that refuses to destroy unmerged work. Both versions journaled.

the contract

785 tests. Coded MRS-* envelopes · frozen exit domain {0,1,2,3,4,130} · one harness seam (FR-52), import-linter-enforced · wrap, never absorb.

# provision an isolated loop home
marshal init pyforge-mason
# every blocking finding named up front
marshal preflight pyforge-mason
# the engine runs, wrapped — never absorbed
bmad-loop run
# verify the fleet’s isolation on demand
marshal homes
# retire the home; unmerged work refuses
marshal teardown pyforge-mason

Mindset 03 · the triad

The execution doctrine

Skills execute
The unit of execution

Everything agentic ships as a skill — BMM’s 51 workflows, community plugins, freshly forged domain skills.

The harness governs
Deliberately not a skill

bmad-loop, verify gates, deterministic tools — the thing that governs the agent cannot be a thing the agent authors.

Verdicts independent
Never self-judged

Warden holds compliance, Doctor holds health — and Doctor judges Marshal’s own row. The hand that builds is never the gate.

Ratified 2026-07-31

Marshal sequences on verdicts it never authors — gating reads each station’s durable verdict artifact, pinned to the revision it judged. Marshal never runs the judge.
