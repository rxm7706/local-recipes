# Enforce the spec. Run the line.

### Validated code, not vibes.

Marshal is the BMAD-method orchestrator of the PyForge factory: specs in, validated code out, every run visible. Autonomy as a **gradient** — attended stories first, then unattended loops wrapped in verify gates and quality gates, with a hard rule that anything the agent cannot safely decide **escalates to a human** instead of being guessed.

---

## Why it matters — three outcomes

**Anti-vibe by construction**
Strict structural inputs only: per-story intent contracts, multi-lens adversarial review, a deterministic verify gate before every merge — a deviating sub-agent is flagged and corrected, never waved through.

**Many lines, one floor**
Per-loop worktree homes with single-sourced state let concurrent loops run on one machine — proven live by the Warden wave riding beside main-checkout work.

**Every run stays visible**
Run journals, sprint feeds and merge-subject conventions feed the public program console — progress is derived from ledgers, never hand-trusted.

## The promise

A story enters as an approved spec and leaves as merged, verified code — or it pauses for a human. There is no third path.
