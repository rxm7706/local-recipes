# Master ecosystem script — PyForge: Dream to Code

> **Artifact class: master script** — scene / visual / voiceover triples for `bmad-manticore` video production. Interleaves the Charter story, the Marshal deck narration, and the infographic fact base into one long-form shoot-ready document. Sources: `docs/dreams/pyforge-charter.md`, `pyforge-marshal-narration-2026-07-31.md`, `pyforge-marshal-infographic-2026-07-31.md`, `pyforge-genesis-narration-2026-07-31.md`. First instance of the class seeded by `docs/dreams/video-scripts.md`. 27 scenes, ~12–15 min at documentary pace.

---

## Scene 01 — Cold open: the two failure modes

**Visual:** Dark screen. Two terminal windows split-screen: left, an agent burning tokens against a wall of red tracebacks; right, a human drowning in a review queue. Marshal infographic §01 stats animate in: **128** and **0**.

**Voiceover:** Autonomous coding fails two ways. Left unattended, agents ship plausible-but-wrong code — confident, fast, and subtly broken. Supervised closely, humans review everything, and the speed you bought evaporates into meetings. Every team building with AI hits this fork. PyForge refuses it. One hundred twenty-eight stories shipped through an automated line — and zero frozen-surface violations ever reaching a merge. Not by trusting the machine. By structuring it.

**On-screen text:** `Unattended → plausible-but-wrong · Supervised → speed evaporates · PyForge → structural`

## Scene 08 — The doctrine

**Visual:** Deck slide 05. Three columns, then the dark banner slams in: "Ratified 2026-07-31."

## Scene 11 — The engine, wrapped — never absorbed

**Visual:** Terminal: `bmad-loop run` executing; a red boundary box drawn around it labeled FR-52.

**Voiceover:** At the center of the build tier sits the engine: bmad-loop. Unattended, gated development loops — run, resume, resolve, sweep. Marshal wraps it and never absorbs it. Wrap, never absorb means the engine stays upstream, improvements flow both ways, and a fork — if it ever comes — is a bounded swap, not a rewrite.

## Scene 12 — Shipped: the marshal CLI

**Visual:** Deck slide 09. The real session cadence types itself out: init → preflight → bmad-loop run → homes → teardown.

**Voiceover:** Epic One landed ten of ten stories. Six commands exist today. Marshal init provisions an isolated loop home — its own worktree, its own branch, its own backlink to shared state. Preflight names every blocking finding before minute zero, not minute ninety. Homes proves that parallel lines are genuinely isolated. Config composes layered policy with per-key provenance. Teardown refuses to destroy unmerged work. And every finding arrives as a coded, machine-parseable envelope — because the next reader of an error message is usually an agent.

**On-screen text:** `785 tests · MRS-* envelopes · exit domain {0,1,2,3,4,130}`

## Scene 13 — A story's journey down the line

**Visual:** The infographic §04 journey table as an animated conveyor: spec → gate → build → review → verify → merge.

**Voiceover:** Watch one story travel the line. A per-story intent contract is drafted — the spec. At the gate, the run pauses for approval: a human, or a deterministic scope-check. The build happens in an isolated story worktree. Then the review: independent lenses hunt adversarially — edge cases, verification gaps — and this pass is standing at every autonomy level; it is never traded away. Only when the full suite runs green does the loop merge, mechanically, with a labeled commit. What ships is what was specified.

**On-screen text:** `spec → gate → build → review → verify → merge`

## Scene 14 — Graduated autonomy: the gradient

**Visual:** The L1–L5 strip from infographic §06; the L3 cell pulses: "the production ceiling — running here today."

**Voiceover:** Autonomy here is a gradient, not a leap of faith. Level one, assistive — the human drives. Level two, task-based — discrete tasks under explicit approvals. Level three — conditional autonomy inside machine-readable context gates. That is the production ceiling, and it is running here today: unattended loops inside boundaries, where anything the agent cannot safely decide escalates to a human instead of being guessed. Levels four and five — governance-only and self-governance — are the roadmap, reached by evidence, not enthusiasm.

**On-screen text:** `L3 · Conditional / Context Gates — running today`

## Scene 15 — The supervisor is the product

**Visual:** Deck slide 10. Split: a tmux session left; an independent watcher process right, its eye never blinking.

**Voiceover:** Here is Marshal's differentiator: the supervisor watches from outside. A separate process the agent session cannot disable, silence, or mislead. Idle strands — a session that stopped producing but never exited — are detected from observable output in minutes, not discovered at the token cap. Every run has a ceiling, and a breach stops with a named reason, never a silent deferral. The journal is written before the act, so even a killed run keeps its record.

**On-screen text:** `Watched from outside · named stops · journal-first`

## Scene 24 — The operator's guide

**Visual:** The which-verb-when table scrolls; each row's verb types itself in the terminal font.
