Knowledge is lossy

Scattered

Hallucinated

An agent that can't see the graph makes it up. Hallucination is a context problem, not a model problem.

The cure · the compile loop

raw/ → wiki → answers

Capture

Every load-bearing decision lands in the record as it happens — memlogs, ADRs, retros, realization logs.

Curate

Dedup, supersede, link. Memory that stays true — not a landfill.

Compile

Artifacts as nodes, references as edges — the graph built nightly from the tools the team already uses.

Answer

Recall surfaces so every session starts already knowing what the team knows.

The differentiator

Memory that stays true

Accumulation without curation

A landfill that misleads — stale claims recalled as fact, superseded decisions steering new work wrong.

Scribe's discipline

Supersede, dedup, link. Corrections land at the source; every claim carries its date; recalled memories are point-in-time, verified before trusted.
