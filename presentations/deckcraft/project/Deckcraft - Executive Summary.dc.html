DECKCRAFT
The deck pipeline · PyForge
Editable decks, from primitives, behind the firewall
The AI writes the prose and drops the user before the file exists.

A prompt in. An editable deck out. No cloud.

Deckcraft is the plumbing: a conda-forge-native Python package that turns a prompt or a document (PDF / DOCX / PPTX / Markdown / XLSX / URL) into an editable PowerPoint deck plus a round-trippable Marp source — running entirely on local hardware and local LLMs, and surfaced through the AI tools the user already has rather than one more browser tab.

The output
Editable means editable

100% of text, shapes, charts and diagrams are native DrawingML; zero rasterized content — verified by automated structural inspection of the generated file, not asserted in a README.

The posture
It works where the cloud can't

Zero outbound calls after the first-run model download; every V1 feature verified under unshare -n in CI. Conda-forge-only runtime, weights air-gappable via DECKCRAFT_MODEL_DIR.

The reach
Inside the assistant you're in

Claude Skill + MCP stdio server + typer CLI at V1 — 3 of 6 surfaces — plus a conda-forge recipe, so colleagues install it from the mirror their org already pulls.
