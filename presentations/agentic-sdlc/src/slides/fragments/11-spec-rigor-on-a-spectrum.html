HOW MUCH RIGOR

How strictly is the spec enforced?

Spec-first
Seed, then drift

A spec seeds the first generation. Once code exists, the doc is allowed to go stale — no guarantee it still describes the system.

Spec-anchored · BMAD
Living, enforced

The spec evolves with the code. Tests and grounding hooks run on every change; drift fails the build instead of accumulating invisibly.

Spec-as-source
Humans never touch code

Every change starts and ends in the spec; code fully regenerates. Needs a determinism guarantee most teams don't have yet.

Three rigor levels, one spectrum. BMAD sits at spec-anchored — the sweet spot for production systems: enough discipline to prevent drift, without requiring the code to disappear entirely.
