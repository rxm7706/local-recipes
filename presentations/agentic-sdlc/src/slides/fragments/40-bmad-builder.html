When the roster doesn’t cover your domain, build your own agent

Everything is a skill — a folder with a SKILL.md (open Agent Skills standard). The builder walks you there by conversation, not configuration. Agents come in three types:

STATELESS
Every session fresh

A persona and capabilities, no memory. Formatters, diagram generators, focused domain experts.

MEMORY
Remembers you

Keeps a persistent sanctum of identity & knowledge files, re-read each launch. Coaches, writing partners, advisors.

AUTONOMOUS
Works unattended

Adds a PULSE file and wakes on a schedule — monitoring, curation, maintenance between sessions.

Package skills into modules, validate them, and distribute via GitHub — the same mechanism that ships TEA, Game Dev Studio, and the Creative Intelligence Suite.
