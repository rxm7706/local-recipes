Responsibilities

The three crafts

01 · Recipe crafting

Modern v1 recipe.yaml for conda-forge — platform selectors, multi-outputs, architecture skips, compiled with rattler-build.

02 · Library distribution

Release pipelines synchronized — the same library ships simultaneously as a PyPI wheel and a conda package.

03 · Environment binding

Conflicting dependencies across pip and conda resolved and cemented into single, unified environment lockfiles.

# build a modern v1 conda-forge recipe
mason recipe build ./recipes/recipe.yaml
# ship to both indexes at once
mason package --ship pypi,conda-forge
# cement the unified environment
mason environment lock --output conda-lock.txt
