The Design↔Code bridge

01 · Seed

A Design project per deck, bound to the Modernist system, pre-seeded with a contract-compliant starter prototype — proven by extract + build before it crosses.

02 · Design

The human iterates visually at claude.ai/design — no repo mechanics, no file juggling.

03 · Pull

"pull marshal" — the prototype lands in the repo, extracts, builds, and ships its export set. Zero downloads, ever; etags catch mid-edit conflicts.

# the loop the pilot proved
seed → Design project + starter deck
design → human refines visually
pull → etag-checked read → repo
# then, automatically
extract → build → deck-export → commit
