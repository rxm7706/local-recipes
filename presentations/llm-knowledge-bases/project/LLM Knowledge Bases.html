05 · data flowsthree loops through the same stack
// color = intent

Three flows. One
shared substrate.

FLOW 01 Ingestion
triggered by · new file in wiki/raw/
  1. sensor detects raw file
  2. ingester parses + normalizes
  3. compiler writes wiki/compiled/
  4. linker wires backlinks
  5. push to Docs UI via REST
FLOW 02 Audit
triggered by · weekly schedule
  1. schedule fires lint run
  2. linter scans wiki/compiled/
  3. report → wiki/outputs/
  4. fix request → compiler
  5. repair merges upstream
FLOW 03 Query
triggered by · human question · CLI or UI
  1. ask routed to oracle
  2. oracle runs wiki-search
  3. draft → wiki/outputs/
  4. handoff to compiler
  5. filed as new wiki page

18 · contractsspec-kit + agent-skills
// verified tools only

Every tool is a contract
plus a skill.

spec-kit
JSON schema defining the tool's inputs, outputs, and failure modes. Agents cannot call unvalidated shapes. No hallucinated args.
+
agent-skills
The Python runtime. Pure function. Deterministic. File I/O, HTTP, parsing. Logged via OpenTelemetry.
read_file
read-file.json
extract text from local docs · pdf, html, md
write_wiki_markdown
write-wiki-markdown.json
append or update wiki/compiled/ page
search_wiki

BM25 across the wiki · returns ranked snippets
lasuite_api_push
lasuite_push_schema.json
POST / PATCH markdown to La Suite Docs
