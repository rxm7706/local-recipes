# llm-knowledge-bases

A local twin of the **LLM Knowledge Bases** Claude Design project — one
standalone `LLM Knowledge Bases.html` poster, pulled byte-exact, verbatim,
plus the `deck-stage.js` runtime it loads by relative path (so the poster
actually renders standalone). Like `six-quarter-roadmap`, this is not one
of the fourteen `pyforge-*` station decks and is not built through the
React + Vite deck-family pipeline.

**Scope note.** This Design project also carries a large amount of content
unrelated to `local-recipes` or the PyForge Guild: a `Sentinel-Build-Spec-
vlatest.md` build spec (and its dated `archive/`), two `Sentinel-*-Deck-
*.html` decks, `scripts/`, `tokens/`, and `screenshots/` for that same
separate effort, plus `COMMIT_MSG.txt`/`PR_BODY.md` for an unrelated repo's
pull request — none of it carries a `github.md` bridge record tying it to
this repo (only `agentic-sdlc` and `six-quarter-roadmap` carry one at all;
most twins have none). Only the one file matching the Design project's own
name is mirrored here; the rest is left in Design, untouched. (One further
file, `uploads/Gemini-Infographic-Sentinel-Knowledge.png`, is a ~6.4 MiB
binary `read_file` cannot return at all regardless of scope.)
