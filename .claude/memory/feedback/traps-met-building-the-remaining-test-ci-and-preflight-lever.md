Traps met building the remaining test, CI and preflight levers (2026-11-27, PR #2421; marshal Story 127.1, doctor Story 68.1, steward Story 117.29): (1) Profile a slow test before sharding it. Marshal's two slowest live tests spent their time in the TEA generator, not in the tests. _bmad/scripts/bmad_tea_playwright.py compiled one bounded regex per story and test file (342,612 for marshal), which overflows re's 512-entry cache, so every compile missed: 95% of the render. Matching the story token against the stem's contiguous _-separated parts keeps the rule and cut the eight-station render from 12.49 to 0.27 s. Prove a generator rewrite by rendering every station before and after and diffing the two trees (diff -r empty), and pin the old rule in a table test. (2) A detector's time alone is not its time inside detectors-ci. capability-effect took 15.6 s alone and 76.7 s inside the aggregate, where its 45 serial whole-tree git greps contend with the other detectors. Running a project's uncached greps in a ThreadPoolExecutor (at most 8), each with its own cache dict merged afterwards, gave 6.8 s alone and 10.1 s inside, with the same 901 finding lines. Measure the gain where the detector runs, not only alone. (3) Changing the TEA generator turned docs-currency red on docs/reference/test-charter.md, whose claims cite it. Re-verify the page, move its verified: date, add a memlog line on the Spec that governs it, and stamp that Spec scoped. (4) The mypy cache's restore keys both carried pixi.lock's hash, so every PR that moved the lock ran mypy cold (58 s; Lint and types took 157 to 178 s on PRs #2415 and #2417, against 77 to 102 s otherwise). A last restore key without the lock hash takes main's newest cache; mypy re-checks each module by its source hash. Not yet seen on a lock-moving PR. Diff each feed against the primary's before copying, and expect sync repairs beside your own keys. The fix is a run-alone slot in the preflight scheduler, never a weaker assertion.
