One durations file serves all three, stored from empty with --store-durations under PYTEST_XDIST_AUTO_NUM_WORKERS=4 by running the task itself; ids from the run whose rootdir is the repository root (tests/packaging, scripts/tests) sit beside the package-relative ones. Check that no run is left with no tests in any shard (pytest exits 5): run every shard as CI runs it and add up the counts (351 + 286 = 637). (2) Write the option as --durations-path=<path> in PYTEST_ADDOPTS; the space form can move pytest's rootdir. (3) A shard repeats every run's start-up. Measure a job's start-up against its test time before sharding it, and read the gain from the PR's own CI run. (5) A matrix job uploads one artifact per shard: rename the report to <half>-<group>.json, name the artifact <half>-<group>, and check the gate already globs both (coverage-atlas-*, atlas-live*.json).
