Traps met sharding Platform CI's test job and building the local preflight levers (2026-11-26, PRs #2409 and #2410; steward 117.23 and 117.24): (1) A suite that runs pixi run -e <env> inside its tests races once sharded: the first run of an environment builds and reinstalls its path packages, so two xdist workers starting it in the same millisecond let one uninstall pyforge-warden while the other ran it (exit 1, empty stdout, a JSONDecodeError in the test). The unsharded job hid it by test order. Install the environment once, under a file lock in the parent of pytest's base temp directory (src/platform/conftest.py pyforge_warden_env); src/platform/tests/test_pixi_environment_first_use.py reds a module that runs an environment without its fixture. (2) pytest reads a bare option value that names an existing path as a test path when it finds the rootdir: --durations-path ../../tests/durations/platform.json moved the rootdir to the repository root and dropped src/platform's addopts (--ds, --import-mode=importlib, an --ignore), giving 15 AppRegistryNotReady errors. Write --durations-path=<path>. (3) Shard durations measured on a 16-thread laptop split unevenly on a 4-core runner (worker spans 42 to 58 s in one shard, 23 to 26 s in another). Measure them from CI: each test's time is the gap after the previous finished test on the same worker in the -v log; skip each worker's first gap, which holds its database setup. Each Platform CI shard also pays about 76 s that sharding does not split (containers, checkout, install, pytest start). (4) Run a full preflight with nothing else on the machine: beside other CPU work, doctor's CPU speed-budget test went red at a median of 5.00 s against 5.0 s. Read a lone red there as load first. (5) To measure a touched run, use a scratch clone with refs/remotes/origin/main set to its HEAD, so the selection sees only the probe edit, and pass pr-preflight -- --keep-going, because the probe reds spec-surface and stop-on-red cancels the lanes under test. (6) Read the journal's lane timeline before building a scheduler change, and measure it in a clone before keeping it: the serial lanes already ended inside the xdist lanes' tail (they cost nothing), and herald's two suites side by side gained nothing on an 8-core machine, because the live half alone keeps 9.3 cores busy; hyperthreads are not free cores. (7) workspace clean --delete refuses a worktree that holds its own copy of a Tier-3 feed (sprint-status.yaml) the primary checkout also holds. Check the primary's copy has every key, remove the worktree's copy, and run the clean again. (8) An authored page that names a source under sources: reds docs-currency once that source moves, and the touched preflight defers detectors-ci to CI. Run detectors-ci or the full scope, then re-verify the page: its text, its verified date, a memlog line on doctor's Spec, and a scoped stamp. (9) A branch stacked on another PR needs no rebase: once the base merges with --merge, the stacked PR shows only its own commits.
