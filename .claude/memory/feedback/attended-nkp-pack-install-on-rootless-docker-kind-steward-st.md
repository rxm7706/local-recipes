Attended NKP pack install on rootless Docker/kind (steward Story 118.2 → 118.5, 2026-10-31): (1) pack Argo CD Applications must name NIC's nebari-apps AppProject — foundational admits only NIC's namespaces and chart repos (InvalidSpecError on both the destination and the oci:// repo); (2) kubectl wait on an Application Argo CD has not created yet fails at once with NotFound (nebari-root polls file:// every 3 min) — refresh nebari-root and poll for existence; (3) health=Healthy is transient on a fresh Application and stale on a re-run — require a Succeeded operation whose syncResult.source equals what you rendered, never .status.sync.status=Synced (SSA drift keeps nebi-pack OutOfSync while Healthy); (4) a key: null meant to delete a chart default never reaches Helm through valuesObject (the apiserver drops nulls) — render helm.values as a YAML string; (5) chart 0.1.7 renders landingPage.iconLight/iconDark that the NIC 0.14.0 operator (0.1.0-alpha.20) CRD lacks, so SSA refuses the NebariApp — null them; (6) pods cannot resolve *.nebari.local on kind, so the hub needs keycloak.backchannelURL AND KC_REALM_API_URL (the role-gated /shared lookup derives its admin URL from the public issuer) and nebi needs auth.oidc.discoveryURL; (7) z2jh's block-cloud-metadata init container dies on rootless kind (iptables filter table missing) — blockWithIptables false; (8) the chart's NFS server cannot start in the node's user namespace (rpc.nfsd: Unable to access /proc/fs/nfsd) and the kernel NFS client refuses (mount.nfs: Operation not permitted) — /shared needs rootful Docker or an RWX class; (9) a pack sync that waits for a crash-looping hub stays Running forever and blocks auto-sync — patch status.operationState.phase=Terminating; (10) pixi run --manifest-path <primary>/pixi.toml runs the task FROM THE PRIMARY ROOT: a ledger sync run that way wrote the primary's tracked ledger from a worktree session — run scripts with the env's python from the worktree cwd instead.
