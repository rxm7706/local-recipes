Traps met making herald's test builds keep the docs pages they already rendered (2026-11-27, PR #2426; herald Story 61.1): (1) Read Astro's own phase timings before choosing a fix: a build's log stamps content sync, type generation, vite, the page render, Pagefind and the sitemap. Of a 7 s build, 4.3 s was content sync, because docs-site/src/loaders/shelf-docs-loader.ts rendered all 94 docs pages every time, where Astro's glob loader keeps an entry whose digest is unchanged. (2) Astro's content store (node_modules/.astro/) outlives a build in the same tree. A custom loader must digest its entries to skip work, and must delete the ids it no longer sees, or a deleted page stays in the store and is published by the next local build. (3) Astro empties the whole store whenever its config changes; it hashes every config key except vite, integrations and adapter. Top-level redirects that depend on a build input (the Kedro-Viz mount) changed between the tests' builds and emptied the store in 6 of 16 builds; a cacheDir keyed by a hash of the redirects gives each variant its own store. (4) A per-page digest is safe only if rendering reads nothing but the page. rehype-shelf-links.js stats every link target to decide where the link points, so keeping pages is opt-in (PAGES_REUSE_RENDERED_DOCS) for herald's test builds, whose copy links a repository no test edits; the Pages build leaves it off. (5) Herald's contract test sees an environment read only as process.env.X, process.env[CONST] through an export const, an injected env.X, or a literal envFlagOn('X'). envFlagOn(CONST) escaped it and the test stayed green with the variable unlisted; write the literal so the test forces the contract row. (6) Under another session's load (load average 8 to 15), single timings swung 79 to 141 s. Alternate off and on runs, and read CPU time (/usr/bin/time) beside wall time: 111 to 88 s and 96 to 79 s wall, 587 to 453 s and 489 to 414 s CPU. (7) Keep measurement instrumentation cheap: hashing each build's fixture tree with rglob took the live half from 76 to 206 s. Copy the file before instrumenting it and restore from that copy before any commit. (8) In a fresh worktree, pixi run -e site docs-site-install fails "failed to activate 'site' ... No such file or directory" when TMPDIR names a folder that does not exist; create it first. (9) A PR can be merged under the operator's account before Auto-fix is asked for; set_monitor then refuses with "already merged". Read the merge and its checks, then still run the post-merge steps; the sprint-status file may already be copied.
