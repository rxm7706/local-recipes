Traps met cutting CI's checkout and pixi setup, and a herald test that failed once (2026-11-27, PRs #2431 and #2432; steward Story 117.32, herald Story 62.1): (1) Test a blob-less clone before proposing one. A local partial clone (git clone --filter=blob:none --single-branch -u "git -c uploadpack.allowFilter=true upload-pack" file://<repo>) cut main's history from 224 MB to 145 MB. But detectors-ci run in it fetched about 8,000 blobs on demand, and chain_currency_sweep_check timed out at 300 s. Count on-demand fetches from git count-objects -v (in-pack) before and after each suite; on CI every such fetch is a network round trip. Full history stays whole for the Detectors jobs. (2) A job's setup-pixi time is its cache restore, which scales with the environment's size. Find the weight with du over .pixi/envs/<env>, share/ included. Playwright's browsers were 680 of each CI environment's MB. Every launch in the code was headless, which runs only chromium-headless-shell, so grep for headless=False, channel= and executable_path before dropping the full Chromium. (3) Dropping a package from a feature changes every environment that composes the feature, the laptop SBOM included. Give the environments that keep it a feature of their own (playwright-full-chromium), so their package sets do not move. (4) After removing dependencies, pixi lock with the pinned pixi (never update) should only remove records. Check that git diff pixi.lock | grep '^+' | grep -v '^+++' prints nothing. (5) pyforge steward estate reconcile regenerates docs/reference/environments.md, docs/how-to/pixi-tasks.md, docs/map.yaml's stamps and the unifying-strategy Dream's environment matrix, and appends and stamps a doctor memlog line. It exits 3 while other Specs still drift. Reconcile those, and then each next governor the scoped stamps expose (here steward, core, marshal and unifying-strategy), one stamp at a time; a loop over spec-surface-check's first drift line does it. (6) A PR that changes pixi.lock misses the pixi cache on every job, because the key carries the lock's hash and PRs write no cache. A smaller environment's faster restore shows only after main writes its cache, so it cannot be measured on that PR. (7) Atlas's WASM smoke test skips until src/shared/packages/pyforge-atlas/wasm/build.py has run; build first, then run it. It finds the headless shell when the full Chromium is gone. (8) The rm safety check refuses a target built from shell variables. Write "${VAR:?}" or a literal path. (9) A check's link carries its job id; gh run list --commit needs the full SHA. gh run rerun <run> --failed re-runs only the failed jobs. (10) A byte-comparison test that names only a path cannot be traced after the fact. Herald's two-builds test failed once with only pagefind/pagefind-entry.json differing, passed on re-run, and did not recur in 23 local builds; its assertion now carries pages_astro.differences_report, which diffs the first few files.
