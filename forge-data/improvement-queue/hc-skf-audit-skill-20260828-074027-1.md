## Workflow
`skf-audit-skill`

## Step File
`src/skf-audit-skill/references/init.md`

## Severity
`gap`

## Fingerprint
`fp-975bd0c`

## Finding
Degraded mode (no provenance map found) has no headless-consumable way to supply the current
source-code path.

## Expected
The Invocation Contract's Inputs table (SKILL.md) should name a `source_path`/`source_root`
input, mirroring `degraded`/`dirty_worktree_choice`, so a headless caller can pre-supply the
answer to init.md §5's "Please provide the path to the current source code" prompt.

## Actual
Ran headless with `degraded=true` against a skill with no provenance map. init.md §5's degraded
branch has an interactive-only prompt for the source path with no documented headless default or
pre-suppliable input, unlike every other gate in this step.

## Evidence
- `src/skf-audit-skill/references/init.md:182-184` — "If degraded mode: Ask user: 'Please provide
  the path to the current source code.'" — no headless branch.
- `src/skf-audit-skill/SKILL.md` Invocation Contract Inputs row lists `skill_name`, `skill_path`,
  `tier_override`, `degraded`, `upstream_drift_choice`, `dirty_worktree_choice`, `force` — no
  source-path field.

## Impact
A headless/automated audit run of a skill whose provenance map is missing cannot complete without
the operator directly reasoning about which path to supply, working around the documented headless
contract rather than following it.

## Suggested Fix
Add a `source_path` [optional, required when `degraded=true` and no provenance map exists]
input to the Invocation Contract, consumed at init.md §5's degraded branch exactly like
`dirty_worktree_choice` is consumed at §5b.
