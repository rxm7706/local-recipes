## Local-only files

These files are maintained in this repository and are **not** byte-identical to upstream:

- `package.json` / `package-lock.json` — trimmed scripts; same Astro/Starlight dependency ranges
- `astro.config.mjs` — `SITE_URL`/`base`, four-quadrant autogenerated sidebar, no locales
- `src/content.config.ts` — shelf collection scope and schema
- `src/loaders/shelf-docs-loader.ts` — titles from frontmatter or first `#` heading; `README.md` → quadrant index; heading deduplication

## Layout

```
docs/                          # shelf content (repo root)
docs-site/
  src/content/docs -> ../../../docs
  build/site/                  # gitignored build output
```

## Commands

From the repo root:

```bash
pixi run -e site docs-site-install
pixi run -e site docs-site-build
```
