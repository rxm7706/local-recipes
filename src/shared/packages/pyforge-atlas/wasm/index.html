Feedstock health — client-side (no backend)

This page runs entirely in the browser. It instantiates DuckDB-WASM, loads a statically-hosted Parquet file, and runs the Story D1 feedstock-health query (ci_red = ci_status IN ('failure','error')) client-side. There is no application server: the only HTTP traffic is fetching static assets (the wasm module, the vendored parquet extension, and the Parquet file).
