  11. The Autonomous Loop Breaks at Step 9                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                    
  The SKILL.md workflow ends with "Submit PR using the submit_pr pixi task" — but submit_pr is a CLI command, not an MCP tool. An autonomous agent cannot call pixi run directly; it needs a tool for this. Add a submit_pr MCP tool that wraps scripts/submit_pr.sh.                                               
                                                                                                                                                                                                                                                                                                                    
  12. failure_analyzer.py — 5 Patterns Is Too Thin                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                  
  The error library covers COMPILER_NOT_FOUND, C++ standard, CMake, missing header, and undefined reference. Real conda-forge builds hit dozens of other patterns: Python version mismatches, __init__.pyi stub errors, test failures (ImportError at test time), missing pkg-config / cmake in build, rattler-build
   schema errors. This library needs 20+ patterns to be genuinely useful.                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                    
  13. Vulnerability Scanning Should Use OSV Batch API, Not Full DB Download                                                                                                                                                                                                                                         
   
  The current approach downloads the entire PyPI OSV vulnerability ZIP (can be 300–500MB), indexes it locally, then scans. The OSV API has a POST /v1/querybatch endpoint that accepts [{version, package: {name, ecosystem: "PyPI"}}] and returns only relevant vulnerabilities. For a recipe with 10 deps, that's 
  10 targeted lookups vs. 300MB download. The local DB is only worth maintaining for air-gapped environments.                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                    
  14. Upgrade to FastMCP 2.0+                                                                                                                                                                                                                                                                                     

  The current code uses FastMCP 1.x patterns. FastMCP 2.0 adds:                                                                                                                                                                                                                                                     
  - Context injection: tools can access request context, logging, progress reporting
  - Resource support: expose recipe files, build logs as browsable resources                                                                                                                                                                                                                                        
  - Structured output schemas: return typed Pydantic models instead of raw JSON strings                                                                                                                                                                                                                           
  - Better error propagation: McpError instead of dict {"error": ...}                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                    
  15. SKILL.md allowed-tools Is Too Restrictive                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                    
  allowed-tools: [conda_forge_server]                                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                    
  As demonstrated when generating apple-fm-sdk, the skill needs WebFetch, WebSearch, Bash, Read, Write, Edit to do real work. The MCP tools alone can't handle packages that aren't on PyPI, need GitHub research, or need manual recipe construction. Either expand allowed-tools or document that the skill falls 
  back to direct tools.
                                                                                                                                                                                                                                                                                                                    
  16. settings.local.json Permission Accumulation                                                                                                                                                                                                                                                                 

  The file has 100+ permission rules accumulated from many sessions — including specific absolute paths (/tmp/claude/.../tasks/b1a44ba.output), obsolete pod patterns (KUBECONFIG=/tmp/podman-test/...), and multi-line bash fragments as permission keys (lines 37–44, 76–78). These pollute the allow-list and    
  degrade security posture. The /fewer-permission-prompts skill should be run periodically to clean this up.
