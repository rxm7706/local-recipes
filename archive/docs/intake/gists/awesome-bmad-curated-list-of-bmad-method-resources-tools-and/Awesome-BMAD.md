# Awesome BMad [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of awesome resources, tools, integrations, and tutorials for the **BMad Method** (Breakthrough Method of Agile AI-Driven Development).

The BMad Method is a structured, spec-driven development framework that bridges the gap between upfront planning and IDE-based execution by treating specifications as code and leaning into autonomous AI agents organized as a virtual agile team.

## IDE Integrations

The BMad Method is designed to work directly inside modern AI-powered IDEs. Supported environments include:

*   **[BMad Method UI (VS Code Extension)](https://github.com/bmad-code-org/bmad-method-ui)** — Official VS Code extension providing a sidebar dashboard with sprint & task tracking, progress bars, and workflow command integration.
*   **Cursor** — Full IDE integration via `npx bmad-method install` with automatic configuration.
*   **Windsurf (Devin Desktop)** — Supported via `.windsurfrules` configuration files generated during installation.
*   **Claude Code** — Native integration for spec-driven workflows and agent-based development.
*   **GitHub Copilot** — Compatible via CLI-based spec-driven development workflows.

## Workflow Automation

*   **[n8n-BMAD Framework](https://github.com/crystalmyth/n8n-bmad)** — AI-powered methodology framework for n8n workflow automation teams. Provides 15+ specialized agent personas tailored to n8n syntax, nodes, and integration patterns. Includes a five-command workflow (`/n8n:pm`, `/n8n:arch`, `/n8n:po`, `/n8n:dev`, `/n8n:qa`) for full lifecycle management.

## Web Bundles (Planning Agents)

Web Bundles are self-contained planning agents designed to be imported into ChatGPT Custom GPTs, Google Gemini Gems, or Microsoft Copilot Agents. Download them at **[bmadcode.com/web-bundles](https://www.bmadcode.com/web-bundles/)**.

| Bundle | Description |
|--------|-------------|
| **Brainstorming Coach** | Uses 60+ proven ideation techniques to formulate and refine concepts |
| **Product Brief Coach** | Facilitates creation, updating, and validation of standardized project briefs |
| **PRFAQ Coach** | Amazon-style "Working Backwards" press release and FAQ planning |
| **PRD Coach** | Generates strict, structured Product Requirements Documents with built-in validation |
| **UX Coach** | Two-spine technical spec output (`DESIGN.md` + `EXPERIENCE.md`) bridging design and engineering |
| **Market & Industry Research** | Deep competitive and industry research for technical decision-making |
