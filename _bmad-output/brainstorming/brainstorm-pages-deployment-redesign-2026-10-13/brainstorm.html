Stage 01 · technique

Constraint Mapping

deep — sort real from imagined, attack each. Eighteen constraints dropped on the sorting board; the imagined ones are struck through, every one gets an attack.

Real — keep, make cheaper9
C1real

One deploy-pages caller per repo (Pages = one env; two callers race).

Make it a reusable workflow (workflow_call) that other lanes invoke, never copy.

C4real

Zero third-party origins in the artifact (AD-21 amendment, airgap host).

Keep, but enforce with one allowlist-origin check over build/site, not a 300-line HTML/CSS/JS scanner.

C5real

docs/ never moves (doctor detectors read it).

The symlink stays the architecture.

C8real-ish

Infographics are standalone design-twin HTML and cannot be Markdown.

Serve them verbatim via Astro publicDir; the gallery page is an Astro page listing them.

C9real today

build.py reads presentations/ (658MB) so the runner clones it.

Sparse checkout (presentations/*/project/*.html only, no src/pptx) cuts checkout time and bandwidth.

C12real

Foundry rebuilds this surface (mode rebuild).

Every bespoke line is rebuild cost; prefer upstream tools (Astro, Starlight plugins, upstream validators) over local Python.

C13real

Actions minutes are a paid budget (unifying strategy 2026-09-04).

Path filters + shallow + sparse + no-op deploy skip are budget moves, not polish.

C14real

Lane 1 /console/ is dynamic and not Pages.

The static site gets build-time JSON snapshots (steward ci status --json, facts.yaml), never live calls.

C15real

GitHub Pages has no per-PR preview environment.

Upload the built site as a PR artifact and post one comment with the download link; good enough for review.

Imagined — struck6
C2imagined

Deploy on every push to main.

Path-filter dashboard.yml to the same paths docsite-check uses (docs/**, docs-site/**, docsite/**, presentations/**, docs/dashboard/**, pixi.toml) + workflow_dispatch; 154 cancelled runs/30d vanish.

C3imagined

The Kedro-Viz export must be committed to git to reach Pages.

Hand it over as a workflow artifact (actions/upload-artifact in kedro-viz-publish, download-artifact cross-run in the Pages build) or as a release asset; zero bot commits on main.

C7imagined

The dossier must be a Jinja2 render.

Astro content collections can load dossier.yml directly (file() loader or custom loader); 14 block macros become 14 Astro components.

C10imagined

fetch-depth 0.

Nothing in the build needs history; fetch-depth 1 (verify whether deck_versions reads git log).

C11imagined

The second host needs a flag.

actions/configure-pages gives the correct base_url/base_path on github.com AND on GHE; always use it, delete pyforge.herald.pages_second_host and export_pages_host_env.py.

C18imagined

site-check must build to dist/ while pages-build builds to docs-site/build/site/herald/.

One output tree is enough; drop the dist/ path.

Half-imagined1
C6half-imagined

docs-site/ must stay upstream-identical.

Only 5 files are hash-pinned; everything else is local. Parity does not force the name clash: rename docsite/, not docs-site/.

Open questions2

Candidate for retire (keep at Lane 1 or as a release asset) if nobody external reads it.

Stage 03 · technique

SCAMPER

structured — run on the pipeline itself. Seven levers pulled on every stage of the line.

dashboard.yml→assemble_pages.py→artifact
SSubstitute
  • S1Jinja2 dossier → Astro content collection reading dossier.yml; 14 block macros → 14 .astro components; same YAML, no second template language.
  • S2The custom in-artifact link walker → upstream validate-doc-links.js (already vendored) + lychee --offline over build/site for the rest.
  • S3300-line cross-origin scanner → a 30-line allowlist check (every absolute URL in html/css/js must share the configured origin) plus a <meta http-equiv=Content-Security-Policy> default-src 'self' so a violation is also visible in the browser.
  • S4Committed docs/dashboard/kedro-viz/ → artifact handoff from kedro-viz-publish (upload-artifact, retention 90d) pulled by the Pages build.
  • S5The name dashboard.yml → pages.yml; a workflow named for what it deploys, not for the 2026-08 console it used to deploy.
CCombine
  • S6docsite-check.yml + dashboard.yml → one pages.yml with jobs build (pull_request and push) and deploy (push to main only), upstream docs.yaml shape; one file, one set of path filters, no drift between twin and deployer.
  • S7Herald top menu + Starlight sidebar + landing tiles from ONE registry; today site.yml feeds both menus, map.yaml feeds the sidebar; fold herald rows into map.yaml (doctor's registry) so one file orders the whole site.
  • S8Pagefind index across /, /herald/ and /dashboard/ → one search.
  • S9The dossier's planned CI-surfaces tile + steward ci status --json + doctor fleet-picture → one build-time status.json consumed by the Astro dossier page.
AAdapt
  • S10BMAD-METHOD docs.yaml verbatim (path filters, SITE_URL repo variable, setup-node from .nvmrc) with pixi only where Python is actually needed.
  • S11starlight-llms-txt plugin → /llms.txt and /llms-full.txt at the root for agent readers.
  • S12Upstream rehypeInlineDiagrams (hand-authored SVG, inlined) so docs diagrams stay zero-origin and themed.
  • S13@fontsource npm packages (the fonts already come from them) imported by Astro instead of 25 vendored woff2 files with hand-recorded sha256 rows.
MModify
  • S14Trigger paths; fetch-depth 1; sparse-checkout; concurrency group pages-build with cancel-in-progress true for the build job, group pages (no cancel) only for deploy.
  • S15Deploy job skipped when the built tree hash equals the last deployed hash (no-op deploy skip).
  • S16timeout-minutes on build; a scheduled liveness probe (curl last-modified of the live root vs the latest main docs commit) as a doctor advisory, since a timeout cannot cover a job stuck in waiting.
PPut to other use
  • S17Zip the same Pages artifact as a release asset so the GHE/airgap host downloads the reviewed bytes instead of rebuilding behind a mirror.
  • S18dossier.yml as the source for README.md's estate summary section (one render more, one hand-copy less).
  • S19The Pages artifact as scribe's recall corpus for public-facing facts (compile the built llms-full.txt into the graph).
EEliminate
  • S20Legacy root redirect stubs after a dated sunset; import_artifact.py (one-time migration, 302 lines, done); the dist/ second build path; the pages_second_host flag; the Claude-artifact shell if unused.
  • S21Kedro-Viz bytes from git (11MB, 215 files, stale since 2026-08-15, publish workflow paused).
RReverse
  • S22Astro runs LAST and consumes herald output as data (deck list, dossier sections) so it emits nav and search itself; today herald runs inside the assembler after Astro.
  • S23The enterprise host PULLS (release asset / artifact) instead of running the same CI; pulls need no conda mirror for the Pages build.
  • S24The registry direction: doctor's map.yaml gains a herald section instead of herald's site.yml feeding doctor's sidebar generator.

Stage 05 · technique

Kill the Crown Jewel

constraint — delete the beloved piece, redesign without it. Eight demolition tags hung on the estate's load-bearing parts.

killK1assemble_pages.py 720 lines

docsite output copied into docs-site/public/herald/ before the Astro build (Astro copies public/ verbatim); redirects become an astro.config redirects map generated from a 44-row JSON; mounts collide at Astro build time (duplicate route error); link check = upstream validator + lychee; origin check = 30-line allowlist.

killK2docsite/build.py 867 lines

dossier = Astro content collection over dossier.yml with one page per section and a component per block type; gallery = Astro page over import.meta.glob of presentations/*/project/*Infographic standalone.html copied to public/; family pages = src/pages/herald/decks/[slug].astro reading presentations/<slug>/facts.yaml; fonts = @fontsource imports.

killK3dashboard.yml's unconditional trigger

nothing is lost; docs deploy on docs changes, the dossier's numbers refresh on a weekly schedule run (cron) so stats stay within a week of the tree.

killK4the git-committed Kedro-Viz

kedro-viz-publish uploads an artifact named kedro-viz-export; the pages build downloads the newest successful one (gh run download or actions/download-artifact with run-id); if none exists the mount is skipped and the nav hides the tile — no hard failure.

killK5the pages_second_host flag

configure-pages is authoritative on every host; the how-to shrinks to "Settings › Pages › GitHub Actions".

killK6the dossier as a hand-written document

prose stays, every number becomes a build-time measurement; the 2026-09-13 refresh ritual (step 3 "someone updates dossier.yml") is halved.

killK7the second output tree dist/

site-check becomes pages-check; one build path, one set of tests.

killK8docsite/ as a top-level dir

content moves to docs-site/src/content/dossier/ (YAML) and docs-site/src/pages/herald/*; the name clash dies with the directory, no rename story.

Stage 06 · technique

Failure Analysis

deep — dissect each Pages incident, extract the structural lesson. Nine incident cards; each ends with the lesson that outlives the fix.

INC · F12026-10-06

Deploy parked in waiting for 6 days, 199 cancelled runs, nobody saw.

Lessons(a) stuck detection (steward 99.7 stuck_rules, doctor 43.1) is the fix, timeout is not; (b) fewer runs = fewer chances; (c) a liveness probe comparing live last-modified vs the latest docs commit is a 5-line doctor source.

INC · F22026-10-08

Google Fonts on 45 pages: fixed by vendoring 25 woff2 + a hand sha256 table.

Structural@fontsource via npm makes zero-origin the default; a CSP meta makes a violation visible in the browser, not only in a scanner.

INC · F32026-10-08

docs-site cannot build from a clean checkout (untracked lib/ helper).

StructuralFewer .gitignore exceptions and a fresh-clone build in the PR lane (exists now as a meta test); M3 removes the vendored-helper class entirely if site-url.mjs is replaced by the configure-pages env.

INC · F4since 2026-08-15

Kedro-Viz export frozen; its publish workflow is paused-manually.

StructuralA committed artifact rots silently; an artifact handoff rots visibly (artifact expired → mount skipped → tile gone). Decide retire vs rebuild per the AD-21 owner (atlas).

INC · F5today's run

17 dossier claims drifted, advisory, step green. Nobody reads an advisory annotation on a workflow that runs 7 times a day.

StructuralComputed stats (A10/K6) remove the numeric class; prose drift gets a dated "measured on" stamp per section so staleness is visible on the page.

INC · F6last 30 days

154 of 200 runs cancelled: trigger too broad; the concurrency group hides the waste as "cancelled" rather than "skipped".

StructuralPath filters make the non-runs free.

INC · F73 weeks apart

docsite vs docs-site: minted 3 weeks apart, nobody weighed the clash.

StructuralA top-level dir needs a line in docs/MAP.md's "outside this map" table at mint time; doctor's docs-map-hygiene could red an unlisted top-level dir.

INC · F8since Story 27.2

docs/MAP.md:34 says the dossier publishes at the root (stale).

StructuralProse claims about deploy shape belong in one place (the workflow header or an AGENTS.md pointer), not restated in MAP.

INC · F9dead on arrival

docs/index.md links dreams/pyforge-herald.md, a path the Starlight loader excludes (dreams/ is not a quadrant); the published root hides it, so the source link is dead on arrival.

Structuralvalidate-doc-links should resolve against the PUBLISHED set, not the repo tree.
