- (capability) CAP-1 candidate disposition contract: every commented-out pixi.toml candidate carries exactly one of five dispositions -- blocked (named re-check trigger), archived (upstream dead), stale (dead duplicate/superseded), ready (verified clean), unexamined (honest default). - (capability) CAP-2 version-currency disposition contract: every active dependency below its conda-forge latest (after a pixi update --dry-run re-solve rules out stale-lock) carries one of blocked / platform-gap / deliberate-tradeoff / undiagnosed, naming the exact upstream package + depends/constrains spec read off an actually-resolved build -- never 'something conflicts'. Success: a shared root cause (e.g. one feedstock pin blocking N packages) is recorded once and every dependent package cites it, not re-derived per package.
- (capability) CAP-3 channel-sourcing disposition contract: every active dependency NOT resolved from conda-forge (SelfExplainML or bare PyPI) carries permanent-by-necessity / pending-conda-forge-submission / needs-recheck, cross-referenced against the owning recipes/<name>/'s own cfe-on-conda-forge-status where one exists. Success: a confirmed-on-conda-forge recipe whose package still locks from SelfExplainML (found live this session: fastmcp, slowapi) is flagged as needs-recheck, not silently accepted.
- (capability) CAP-4 durable re-verification: a doctor-owned advisory check (same station/gather pattern as chain_currency_sweep_check) reads each ledger's own recorded verification date and flags when it exceeds a declared staleness threshold -- advisory only, never a PR gate (Warden doctrine, fleet-wide). Success: a ledger last verified beyond the threshold produces a named finding; re-running the audit and updating the recorded date clears it; the threshold is a declared policy value, not a hardcoded magic number.
- (constraint) A blocked disposition must name what would unblock it (Dream's own constraint, carried forward) -- the difference between this ledger and the status quo is a re-check with a named trigger, not requiring someone to remember to look.
- (constraint) Don't re-derive a shared root cause per package (Dream's own constraint) -- one investigation, not N.
- (constraint) Trust local cfe-* metadata as a hint, not ground truth (Dream's own constraint, evidenced live: the langflow entry drifted stale within a single session) -- CAP-1..3 dispositions are always verified against pixi.lock/repodata/a real solve, never against the metadata field alone.
