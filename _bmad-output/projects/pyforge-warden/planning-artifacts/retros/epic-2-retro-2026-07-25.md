## Delivery snapshot

The conda/pixi wedge that makes Warden dual-ecosystem: the conda→pypi map + ecosystem-identity predicate (2.1), non-rendering extraction + the differential-oracle (2.2), the full supported-construct matrix, ratcheted (2.3), honest split coverage + the indeterminate producer (2.4), name-level CVE tier + stale-DB + cross-ecosystem non-merge (2.5), and lockfile extraction — the locked-closure vuln hero path (2.6). **6/6 done; tests grew to 999.**

## What went well

- **The differential-oracle (2.2) is a strong pattern** — validating non-rendering extraction against a rendering oracle catches extraction drift honestly rather than trusting one path.
- **Adversarial review caught two genuine bugs live in 2.2:** a deptry front-door PEP-440 crash and a YAML billion-laughs amplification. External Gemini review on the pushed batches caught two more real defects (a 5-path `stale_findings` propagation gap; a CRLF brace-neutralization bug).
- **The indeterminate producer (2.4)** keeps the tool honest — "can't tell" is a first-class outcome, never silently a pass.

## What was harder than it should have been

- **2.2 deferred at the 3-review-cycle cap despite being sound** (green, every finding forward-scoped) — landed manually. Heavy IO-matrix stories outrun the default review budget.
- **2.6 power-loss recovery:** a crash killed the run mid-dev; the worktree survived with complete, green work that had to be landed by hand — an early instance of the "recover committed work from a dead run" pattern that recurred (6.9).
- **pixi.lock contamination:** running `pixi install` inside a worktree baked worktree-local absolute paths into `pixi.lock`; fix each time is to re-resolve from the repo root.

## Lessons

1. Heavy IO-matrix / extraction stories (2.2 ~194 min, 2.3 ~148) deserve a planning-time split or a higher `max_review_cycles` — the 3-cap deferred sound work.
2. The merge/cleanup phase is the fragile part (2.2 manual land, 2.6 crash recovery), not dev.
3. The deferred-work ledger accumulated correctly-owned findings, several owned by Epic 3's ConfigLoader (3.1) — freeze the mutable policy dicts, the coverage-floor gate.
