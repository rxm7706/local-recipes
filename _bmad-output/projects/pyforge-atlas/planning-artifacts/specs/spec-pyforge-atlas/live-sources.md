# Live sources — what fills each dataset, and how it is judged (CAP-64..CAP-68)

Companion to `SPEC.md` (minted 2026-10-18; amended 2026-11-01 by the EGM fleet audit, marshal Story 113.7). One row
per external source a plain or opted-in run reaches. **Parity measure** is the legacy `cf_atlas.db` figure the row
compares against on the same day; the legacy phase letters are `conda_forge_atlas.py`'s phases, which `signals.md`
maps to their nodes. The legacy admin refresh of 2026-10-18 00:27 read nothing for Phases E, J and M (the R1 break);
since mason Story 34.1 (2026-10-26) the legacy reader fills them again, so those rows compare like for like. **Floor**
is what the row is held to: the story-close measurement against the same-day legacy figure (operator ruling
2026-11-01, amending the 2026-10-18 "recorded per story"); a row with no legacy figure is held to its measure.
**Credential:** `—` public, unauthenticated; `opt-in` runs only with `PYFORGE_ATLAS_CREDENTIALED=1`. **CAP** is the
capability whose success counts the row: CAP-64's success counts only its own rows.
