## 2026-08-15 — SPEC.md's own surface declaration was broken; fixed

`SPEC.md`'s `surface:` list declared `scripts/` (no wildcard) intending to cover whatever
detector script CAP-1 shipped, but `_glob_to_re`'s own documented rule ("a pattern with no glob
chars matches exactly") compiles a bare `scripts/` to `^scripts/$` — which matches nothing, since
`scripts/` is a directory, not a tracked file. `scripts/bmad_loop_baseline_drift_check.py`
therefore read `[ungoverned]` on `origin/main` right after the prior entry's own PR (#511) merged
— confirmed on a clean detached worktree at `origin/main`, so this was a real gap the prior
entry's own verification missed (a false negative), not something a later change introduced.
Narrowed `surface:` to the exact new file (`scripts/bmad_loop_baseline_drift_check.py`) rather
than widening to `scripts/*`/`scripts/**`, which would have made this spec govern every other
unrelated script in the directory too. Baseline re-stamped for this spec only; `python
scripts/spec_surface_reconcile.py` confirmed `OK` afterward.
