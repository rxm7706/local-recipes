- (decision) Root cause is ONE disease at two granularities, not two unrelated bugs: the reconciliation claim is made at the wrong level. Baselines stamp all-or-nothing when they should be per-spec; drift clears per-spec when it should be per-file. Fixing granularity resolves both symptoms, which is why they are specced together rather than as separate efforts.
- (capability) CAP-1 baseline stamping is scopeable. intent: an operator settles one spec's baseline without accepting any other spec's pending drift. success: --write-baseline --spec NAME merges only that spec into the committed baseline, leaves every other entry byte-identical, and errors (exit 2) on an unknown spec name.
- (capability) CAP-2 a moved contract reconciles only the paths it names. intent: a memlog entry stops speaking for governed files it never mentions, so unrelated activity cannot launder pending drift. success: with the spec's memlog moved, a drifted file NAMED in the memlog clears while an unnamed one reports [drift-presumed]; appending an unrelated memlog entry no longer changes the verdict for an untouched governed file.
- (capability) CAP-3 the standing 61 findings are worked to zero by category. intent: the operator can act on the verdict because every finding is dispositioned rather than carried. success: each [no-baseline] scoped-stamped, each [drift] genuinely reconciled through its spec or scoped-stamped with the reasoning recorded in that spec's memlog, both [ungoverned] files given a surface or allowlist entry, the [stale-allowlist] pattern removed.
- (capability) CAP-4 the cleared gate is defended by tests that fail for the right reason. intent: the fixes cannot silently regress into the blanket behavior they replace. success: both are mutation-tested BOTH ways — removing --spec scoping re-reds the isolation test, and reverting to the per-spec short-circuit re-reds the laundering test — and spec-surface-check exits 0 on main.
- (constraint) Fix the granularity; do NOT weaken the gate. Widening a threshold, allowlisting the noisy specs, or making drift non-gating would clear the red without making the signal true — Charter section 6 forbids a station relaxing its own gate rather than meeting it.
- (constraint) .memlog.md history is append-only and is never rewritten. The per-file rule READS memlog text; it must not edit, reorder, or normalize any memlog to make matching easier.
- (constraint) A memlog that names no paths is NOT an error. Most existing entries predate any naming convention, so the per-file rule degrades to a visible [drift-presumed], never to a hard failure — otherwise the gate reds for every historical entry, reproducing the unclearable red in a new shape.
- (constraint) [drift-presumed] is INFORMATIONAL and never gates. Its purpose is making an unproven set visible; a gating variant would be the same unclearable red renamed.
- (constraint) A scoped stamp MERGES into the committed baseline. Rewriting from the in-memory current set would silently drop every spec not named on that invocation.
- (decision) Path matching is LITERAL substring on the repo-relative path, the form these memlog entries already cite files in. Deliberately not fuzzy or NLP-inferred: inferring reconciliation intent from prose would reintroduce exactly the presumed-reconciled blanket this replaces.
