- (decision) AD-3: hexagonal/ports-and-adapters paradigm -- bridge-core (domain: etag rules, conflict detection, directional-crossing enforcement) depends only on a DesignTransport port interface; two adapters (McpTransport primary using official mcp>=1.28.1 SDK already pinned repo-wide, AgentSdkTransport fallback headless wrapper) implement it. bridge-core never imports a concrete transport.

- (decision) AD-5: per-deck bridge state persists in a repo-local state file (.herald/bridge-state.json), NOT re-derived from README parsing alone -- keyed by slug, storing linked Design project id + per-artifact last-seen etag (prototype, each marp source, standalone bundle, each derived export file) + last-pull timestamp. Resolves the PRD's undetermined state-persistence question.
- (decision) AD-6: typed exception hierarchy (HeraldError base -> SeedConflictError, PullConflictError, ExportConflictError, TransportUnreachableError, AuthError) each bound to a fixed exit code, caught once at the CLI boundary; stdout carries only machine-readable success output, ALL diagnostics/conflicts/errors go to stderr -- mirrors pyforge-warden's stream discipline (NFR-I3 precedent).
