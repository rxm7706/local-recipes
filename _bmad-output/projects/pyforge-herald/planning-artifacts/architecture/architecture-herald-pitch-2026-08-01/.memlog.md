- (decision) Paradigm: Design-Code-Bridge with Etagged Pull Model — Single immutable Design prototype per station is source of truth (etagged .dc.html, tracked). All code-side artifacts derive via pull model. Conflicts detected by etags, never silent overwrites.
- (decision) Design Source of Truth — One .dc.html file per station (9 total) is the immutable design prototype. Tracked in git. All markdown/PPTX/narration derives from it. Design edits happen in Claude Design cloud; Code pulls etagged copies.
- (decision) Multi-Format Export Pipeline — Design → Pull (etagged) → Markdown (marp) → PPTX (deckcraft) + Narration extraction → HTML deck engine + Video scripts. Each format has specific ownership/regenerability.
- (decision) Artifact Tracking Strategy — Track source + final deliverables (design protos, markdown, PPTX, narration, SVG infographics). Gitignore intermediates (fragments.json, dist/, assets/, .mp4) as regenerable. 62% footprint reduction vs unoptimized.
- (decision) Modernist Design Tokens — Single token source (Figma variables) rounds through design-tokens.json → PPTX templates → deck engine → video production bible. Tokens enforce consistency across all 9 stations.
- (decision) Nine-Station Replication — Framework (Design-Code-Bridge, Deckcraft, Video-Scripts, Modernist-Identity) applied identically to all 9 stations. Per-station content varies (thesis, pain point, personas). No re-engineering per station.
- (decision) Narration Script Extraction — Extract speaker notes mechanically from Design protos → narration-YYYY-MM-DD.md per station. Tracked for video pipeline readiness. Enforced blacklist via linter.
- (decision) Video Pipeline Boundary — Herald orchestrates narration extraction + real screen-recording sourcing. BMad-Manticore is downstream (voice, graphics, SFX, rendering). Herald does not render video.
- (constraint) Immutability of Design Prototypes — Design .dc.html files are immutable at the Code side. All changes originate in Claude Design; Code pulls, never pushes code-side edits back to Design.
- (constraint) Etagged Round-Trip Safety — Every Design ↔ Code transfer includes etag validation. Write operations fail if etag mismatches, preventing silent overwrites. No exceptions.
- (constraint) No Fabricated Demos — All screen recordings in video output are real, recorded from actual product. No AI-generated mockups, synthetic UI, or fabricated product demos.
- (constraint) Narration Voice Identity — Narration must match published voice character (WPM, speech patterns, tone markers). Blacklist enforced by linter before any video render.
- (constraint) Modernist Token Authority — Figma is the authority for design tokens. Token updates must flow Figma → design-tokens.json → templates. Never hardcode colors/fonts in templates.
- (constraint) Multi-Surface Readiness — All artifacts must be production-ready before shipping. No "preview" or "draft" states. PPTX opens in PowerPoint; HTML renders without errors; SVG renders inline.
