## Five findings worth keeping

1. **The reference figure was a bundle.** The 411,764 B "Warden exemplar" everyone had been
   measuring against was a Claude Design bundle — 192,472 B of content plus ~205 KB of base64 fonts
   and runtime. Nine months of "aim for 411 KB" was aimed at a number that never described a poster.
   *Lesson: measure the artifact, not the container.* (Story 20.10.)
2. **A poster goes stale the moment it lands.** Its own merge moves the fleet counts it prints. CAP-5
   caught that within minutes of round 1; the repair had to be minted as CAP-6 mid-epic. Detection
   without repair is a tax, not a capability.
3. **Deriving from the working tree is deriving from nothing.** `recipes_count` read the filesystem
   and reported 7872 in a checkout with untracked scratch recipes, 7864 tracked. Sources must be
   things CI can see.
4. **Two readers of the same file will disagree.** `--check` parsed HTML; `--refresh` used a regex.
   They agreed on the ten live posters and diverged on comments, `<script>`, quoted `>` and nesting —
   invisible until someone wrote an unusual mark. One parser now serves both.
5. **A frontmatter key can be silently duplicated.** The Spec memlog carried two `updated:` keys and
   PyYAML kept the earlier one, so the log read as older than it was. Found only because a reviewer
   read the file rather than trusting it.

## What worked

- **Dream → Spec → Story before code**, including for CAP-6 minted mid-epic. Every capability has a
  contract; nothing was hand-implemented from an idea.
- **Four-layer independent review** on both code stories: 45 findings on 20.2, 31 on 20.14. The one
  `high` (capability counts reading prose mentions, wrong in three ledgers) came from a layer that
  had no context about how the code was produced.
- **Worktree-per-story with one PR per deck.** Eight parallel agents, a second Claude session
  committing to the same repo throughout, zero merge collisions.
- **Looking at the rendered PNG.** Every poster had real defects on first render — SVG captions
  outside their boxes, colliding labels, a clipped footer. None would have been caught by a gate.

## What to change

- `--refresh` cannot fix hand-counted prose, swept SVG labels, or `inline-flex` fusing a marked
  token. All three are now in `infographic-standard.md` § *Three hazards*.
- The `tests_collected` row exists only under `--with-tests`, so a poster printing it needs that flag
  in the sweep. Marshal is the only one today; the sweep script should learn it rather than the
  operator remembering.
- `story-status` reads 0 audited inside a worktree (no Tier-3 feed). Gate checks belong in the main
  checkout or need an explicit feed path.

## Deferred

- Trio lockstep: the Infographic head, Infographic Deck and Executive Summary still carry July facts
  and are marked "standalone ahead" in every deck README.
- Wave C: the four chain decks (unity-data-stack, wasm-analytics-stack, deckcraft,
  presenton-pixi-image) keep their July stubs and unregistered sections.
- Design-side visual polish, deliberately not attempted this session.

## Acceptance

Accepted. All fourteen stories `done`, every acceptance criterion met and verified against the
artifact rather than a report. The Dream advances `specified → realized`: the standard exists, every
PyForge poster meets it, every number resolves to a tracked source, the mirror is proven byte-exact,
the bridge sees the family, and the decay has a mechanical repair that ran successfully on its first
real use.
