## Intent

**Problem:** Every exec summary and marp source was dated 2026-07/08, so the Standard export set (standalone HTML + both PPTX) was stale in every format even after Epic 20 and the 21.1–21.4 local trio recover.

**Approach:** `deck-export` stamps the exec summary and the three dated marp kinds from `facts.yaml` (five ledger ids), dates the marp sources to the rebuild day, then regenerates `html` / `deck-pptx` / `infographic-pptx`. `--format summary|html|pptx|all` selects the stamp+export mix. `find_source` matches only `<slug>-<kind>-<YYYY-MM-DD>.md` so a narration sibling cannot win the sort.

**Always:**
- Facts from `facts.yaml` only; the stamp is a marked band (`data-herald-ledger-band` / `<!-- herald-ledger-band -->`), idempotent on re-run.
- Derived HTML/PPTX are regenerated by marp, never hand-edited.
- `DECK_EXPORT_DATE` pins the rebuild day in tests.

- Never flip steward Epic 44 `blocked`; never `scripts/bmad-switch` from a parallel agent.
